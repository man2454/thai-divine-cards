# ไพ่เทพพยากรณ์ — Thai Divine Cards

เว็บเปิดไพ่แนวเทพไทย ใช้ **HTML5 + CSS + JavaScript ล้วน** ไม่มี Python, Node.js, npm, backend หรือฐานข้อมูล ใช้ไฟล์ชุดเดียวกันได้ทั้ง **ดับเบิลคลิกเปิด `index.html` ในเครื่อง** และ **GitHub Pages**

## เริ่มใช้งานในเครื่อง (Windows / macOS)

1. แตกไฟล์ ZIP โดยรักษาโครงสร้างโฟลเดอร์
2. ดับเบิลคลิก `index.html` ใน Chrome, Edge หรือ Safari
3. ทดลองทั้งสองโหมดได้ทันที ไม่ต้องเชื่อมต่ออินเทอร์เน็ต ไม่ต้องรันเซิร์ฟเวอร์
4. แก้ไฟล์ในโปรแกรมแก้ไขข้อความ แล้ว Refresh หน้าเว็บ (ถ้าข้อมูลเก่าค้าง ให้ Ctrl+F5)

## ฟีเจอร์

- Quick Draw: แสดงไพ่คว่ำหน้า 21 ใบ (หรือตาม `quickChoiceCount`), เลือกทีละใบแล้วกดยืนยันเพื่อเปิด
- เลือกหลายใบจากตาราง (Grid Selection)
- ปุ่มสับไพ่พร้อม Animation ทุกโหมด
- เปิดไพ่ 1/3/5/10 ใบตามที่กำหนดใน Config, ไม่ซ้ำกันในหนึ่งรอบ
- พลิกไพ่ 3D, เปิดคำอธิบายรายใบ, รองรับจอมือถือ
- ใช้ภาพสำรองหากยังไม่มีภาพไพ่จริง

## โครงสร้างไฟล์

```text
thai-divine-cards/
├── index.html                หน้าเว็บหลัก (เปิดไฟล์นี้)
├── css/style.css             รูปแบบ สี และ Animation
├── js/app.js                 การทำงานของแอป
├── js/config.js              การตั้งค่า (จำนวนไพ่ ฯลฯ)
├── js/cards-data.js          ชื่อและคำทำนายของไพ่
├── images/
│   ├── card-back.jpg         ภาพหลังไพ่ (ใส่เองได้)
│   └── cards/
│       ├── 1.jpg             ภาพหน้าไพ่หมายเลข 1
│       └── ...                เพิ่มได้ตามจำนวนไพ่
└── README.md                 คู่มือนี้
```

> โฟลเดอร์ `images/cards/` และไฟล์ภาพยังไม่จำเป็นต้องมีตอนเริ่มทดลอง แอปจะแสดงภาพสำรองให้เอง หากเพิ่มรูปจริงให้สร้างโฟลเดอร์ตามตัวอย่างด้านบน

## ปรับจำนวนไพ่

เปิด `js/config.js` แล้วแก้ค่า:

```javascript
window.APP_CONFIG = {
  "appName": "ไพ่เทพพยากรณ์",
  "cardCount": 80,
  "cardImagePath": "images/cards/",
  "cardImageExtension": ".jpg",
  "cardBackImage": "images/card-back.jpg",
  "defaultDrawCount": 1,
  "drawOptions": [1, 3, 5, 10],
  "allowReversed": false,
  "enableSound": true,
  "shuffleDurationMs": 1300,
  "theme": {"accent":"#d8ae65","background":"#100c16"}
};
```

ตัวอย่างนี้แสดงเฉพาะบางค่า คุณสามารถแก้ค่าในไฟล์จริงได้โดยตรง

- เปลี่ยน `cardCount` เป็น 40, 69, 95 หรือจำนวนอื่น (รองรับ 1–2000 ใบ)
- เพิ่มภาพตามหมายเลขให้ครบ เช่น `images/cards/95.jpg` สำหรับใบที่ 95
- ปรับ `drawOptions` ไม่ให้เกินจำนวนไพ่ และ `defaultDrawCount` ให้ตรงกับหนึ่งในตัวเลือก
- เปลี่ยน `appName`, `subtitle`, `theme.accent`, `theme.background` เพื่อปรับชื่อและสี
- เปลี่ยน `cardImageExtension` เป็น `.png` ได้หากใช้ภาพ PNG ทุกใบ
- `enableSound` เปิด/ปิดเสียง และ `shuffleDurationMs` กำหนดระยะเวลา Animation

## เพิ่มชื่อและคำทำนาย

เปิด `js/cards-data.js` ซึ่งเก็บข้อมูลรูปแบบ `window.CARDS_DATA = { "cards": [...] };` เพิ่มข้อมูลเป็นรายการ โดย `id` ต้องตรงกับชื่อรูป เช่น:

```javascript
window.CARDS_DATA = {
  "cards": [
    {
      "id": 1,
      "name": "ชื่อไพ่จริง",
      "name_th": "ชื่อไพ่จริง",
      "keywords": ["คำสำคัญ"],
      "meaning": "ความหมายจากคู่มือไพ่จริง",
      "love": "",
      "career": "",
      "finance": "",
      "advice": "",
      "reversed": ""
    }
  ]
};
```

ข้อมูลที่ยังไม่ได้ใส่จะแสดงข้อความรอเพิ่มคำทำนาย ไม่สร้างคำทำนายขึ้นเอง ไพ่ที่มีข้อมูลไม่จำเป็นต้องครบ 80 ใบในตอนแรก ข้อควรระวัง: คั่นรายการด้วย `,` และห้ามลบ `window.CARDS_DATA =` หรือเครื่องหมาย `;` ปิดท้าย

## เพิ่มภาพ

- หลังไพ่: `images/card-back.jpg`

- แนะนำให้ใช้ไฟล์ภาพบีบอัดขนาดเหมาะสมเพื่อให้มือถือโหลดเร็ว
- หากยังไม่มีรูป เว็บใช้ภาพสำรองโดยอัตโนมัติ

## อัปโหลด GitHub Pages

1. สร้าง GitHub Repository เช่น `thai-divine-cards`
2. อัปโหลด **ไฟล์และโฟลเดอร์ภายในโปรเจกต์** ไปที่ root ของ Repository
3. เข้า **Settings → Pages → Build and deployment**
4. เลือก **Deploy from a branch**, `main`, `/(root)` แล้ว Save
5. รอ Deploy และเข้า `https://USERNAME.github.io/thai-divine-cards/`

ไม่มี Build Step, Server หรือ Dependency ที่ต้อง Patch ฝั่งแอป ใช้ Relative Paths จึงรองรับ GitHub Pages แบบ Project Site ด้วย

## วิธีแก้ไขและทดสอบ

| ต้องการเปลี่ยน | ไฟล์ที่แก้ |
|---|---|
| จำนวนไพ่/จำนวนที่เปิดได้/ชื่อเว็บ/สีหลัก | `js/config.js` |
| ชื่อไพ่/คำทำนาย | `js/cards-data.js` |
| รูปหน้าไพ่ | `images/cards/เลข.jpg` |
| รูปหลังไพ่ | `images/card-back.jpg` |
| Layout/สี/Animation | `css/style.css` |
| วิธีสุ่ม/เลื่อน/สับ/พลิก | `js/app.js` |
| ข้อความหน้าแรก/เมนู | `index.html` |

**หมายเหตุ:** เว็บอ่านข้อมูลจากไฟล์ JS ที่โหลดผ่าน `<script>` ไม่ใช้ `fetch()` จึงทำงานผ่าน `file://` ได้บนเบราว์เซอร์ทั่วไป การแก้ข้อมูลในไฟล์จะไม่ถูกบันทึกอัตโนมัติจากหน้าเว็บ ต้องแก้ไฟล์เองและ Refresh และการเปลี่ยนไฟล์ในเครื่องไม่เปลี่ยนไฟล์บน GitHub จนกว่าจะ Commit/Push

## ข้อจำกัด

- ไม่มีระบบ Admin หรือฐานข้อมูล; การเพิ่มคำทำนายทำโดยแก้ไฟล์ JS
- ยังไม่มีระบบแปลคำทำนายด้วย AI หรือบันทึกประวัติ
- ไม่ควรนำความหมายไพ่จากสำรับอื่นมาใช้โดยไม่ตรวจสอบกับคู่มือไพ่จริง
- ระบบนี้เป็นเว็บเพื่อความบันเทิงและสะท้อนข้อคิด ไม่รับรองเหตุการณ์ในอนาคต

## อัปเดตการควบคุมครึ่งวงกลมและการสับไพ่

- โหมดครึ่งวงกลม: กดเมาส์ค้างแล้วลากซ้าย/ขวา หรือใช้นิ้วปัดบนจอสัมผัส ไพ่เปลี่ยนทีละใบระหว่างลาก
- ใช้ล้อเมาส์และปุ่มลูกศรซ้าย/ขวาบนหน้าจอได้ด้วย
- แตะไพ่ใบกลางหรือกดปุ่มหยิบไพ่เพื่อเลือก
- ปุ่มสับไพ่: แสดงภาพจำลองแยกกอง สลับกอง และรวมกอง ก่อนสุ่มลำดับไพ่ใหม่จริง
- ปรับเวลาการสับไพ่ที่ `shuffleDurationMs` ใน `js/config.js` (แนะนำ 1800–2400 มิลลิวินาที)
- ไม่มีการใช้ `fetch`, Python หรือ Node.js ในการเปิดใช้งานเว็บ Node.js ใช้เฉพาะตรวจ syntax ระหว่างพัฒนาเท่านั้น


## การแก้ไข V4
- โหมดตารางใช้ `data-card-id` ผูกหมายเลขจริงกับ DOM โดยตรง ไม่อ่านเลขจาก `aria-label` อีกต่อไป จึงไม่เกิดไพ่หมายเลข 0 และไม่เลือกทุกใบพร้อมกัน
- โหมดครึ่งวงกลมใช้ Pointer Events กับพื้นที่เวทีและปุ่มลูกศร
- ปรับคีย์เฟรมสับไพ่ให้เห็นการแยกกองและรวมกอง
- เปิด `index.html` ได้โดยตรงโดยไม่ต้องมีเซิร์ฟเวอร์


## V5: การเลือกไพ่และการเลื่อนครึ่งวงกลม
- **Quick**: แสดงไพ่อย่างน้อย 5 ใบ (ถ้าเลือก 10 ใบจะแสดงอย่างน้อย 10 ใบ) แตะทีละใบเพื่อเลือก/ยกเลิก ไพ่ที่เลือกยกขึ้นและมีกรอบทอง ต้องกด **ยืนยันไพ่ที่เลือก** เมื่อครบจำนวนก่อนเปิดหน้าไพ่
- **Arc**: กดเมาส์ค้างแล้วลากซ้าย/ขวา หรือปัดนิ้วบนมือถือ; ใช้ล้อเมาส์ ปุ่มลูกศรบนจอ หรือคีย์บอร์ดก็ได้ ไพ่ที่ยังไม่หยิบจะไม่ยกขึ้นอัตโนมัติ
- **Grid**: คงระบบเลือกไพ่ของ V4 ที่เลือกทีละใบได้ถูกต้อง
- **Shuffle**: คงเอฟเฟกต์สับไพ่แบบ V3
- ยังคงเปิด `index.html` ด้วยการดับเบิลคลิกโดยไม่ต้องติดตั้ง Runtime ใด ๆ


### จำนวนไพ่ที่แสดงใน Quick Mode
แก้ `quickChoiceCount` ใน `js/config.js` (ค่าเริ่มต้น 21) เพื่อกำหนดจำนวนไพ่คว่ำหน้าที่ให้เลือก โดยแสดง 7 คอลัมน์ × 3 แถวบนคอมพิวเตอร์ และ 3 คอลัมน์บนมือถือ (7 แถว) เพื่อให้แตะง่าย ระบบจะไม่แสดงเกินจำนวนไพ่ทั้งหมด และจะมีให้เลือกไม่น้อยกว่าจำนวนไพ่ที่ต้องหยิบ (หากสำรับมีเพียงพอ) เมื่อเลือกครบแล้วจึงกดยืนยันเพื่อเปิดไพ่

## โหมดที่มีในรุ่นนี้

- **Quick Draw**: 21 ใบให้เลือก (7×3 บนจอกว้าง, 3 คอลัมน์บนมือถือ) เลือกได้ 1/3/5/10 ใบโดยแตะทีละใบ ไพ่ที่เลือกจะยกขึ้น; กดยืนยันเมื่อครบจึงเปิดหน้าไพ่
- **Grid**: แสดงไพ่ทั้งหมดตาม `cardCount` เลือกและยกเลิกได้ทีละใบ ก่อนกดยืนยัน
- โหมดครึ่งวงกลมถูกถอดออกจากหน้าเว็บและระบบการทำงานในรุ่นนี้

เปลี่ยนจำนวนตัวเลือกใน Quick ได้ที่ `quickChoiceCount` ใน `js/config.js` (ค่าเริ่มต้น 21) และจำนวนไพ่ทั้งสำรับที่ `cardCount` (ค่าเริ่มต้น 80) หากสำรับมีน้อยกว่า 21 ใบ จะแสดงตามจำนวนจริง
