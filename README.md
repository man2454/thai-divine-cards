# Thai Divine Cards — ไพ่เทพพยากรณ์ (V7)

เว็บเปิดไพ่พยากรณ์แนวเทพไทยสำหรับใช้งานส่วนตัว สร้างด้วย **HTML5 + CSS + JavaScript ล้วน** ใช้งานได้ทั้งเปิด `index.html` บนคอมพิวเตอร์และเผยแพร่ผ่าน GitHub Pages **ไม่ต้องติดตั้ง Python, Node.js, npm, Backend หรือฐานข้อมูล**

> ไพ่และคำทำนายเป็นข้อมูลที่ผู้ใช้เพิ่มเอง เว็บไม่ได้อ้างว่าไพ่ทุกใบมีความหมายจากตำราจริงแล้ว

## 1. โหมดเปิดไพ่ 3 แบบ

| โหมด | วิธีใช้งาน | จำนวนไพ่ |
| --- | --- | --- |
| **Instant Reading — สุ่มไพ่ 1 ใบทันที** | กด **สับไพ่และเปิด 1 ใบ** → แสดง Animation สับไพ่ → สุ่มและพลิกเปิดไพ่ 1 ใบโดยอัตโนมัติ | 1 ใบเสมอ |
| **Quick Draw — เลือกจากไพ่ 21 ใบ** | เลือกจำนวนไพ่ → แตะไพ่คว่ำหน้าทีละใบ (ใบที่เลือกยกขึ้น) → กด **ยืนยันไพ่ที่เลือก** เมื่อเลือกครบ | ค่าเริ่มต้น 1 / 3 / 5 / 10 ใบ |
| **Grid Selection — เลือกจากทั้งสำรับ** | เลือกจำนวนไพ่ → แตะเลือก/ยกเลิกจากตารางไพ่ทั้งสำรับ → กดเปิดเมื่อครบ | ค่าเริ่มต้น 1 / 3 / 5 / 10 ใบ |

- **Quick Draw** แสดงไพ่ให้เลือก **21 ใบ** ตามค่าเริ่มต้น (`quickChoiceCount`) โดยใช้ 7 คอลัมน์บนจอกว้างและ 3 คอลัมน์บนมือถือ ทั้งนี้อาจแสดงน้อยกว่าหากสำรับมีไพ่ไม่ถึง 21 ใบ
- ปุ่ม **สับไพ่** ใน Quick และ Grid สับลำดับไพ่ใหม่และล้างการเลือกที่ค้างอยู่ ส่วน Instant รวมการสับและเปิดไว้ในปุ่มเดียว
- ไพ่คว่ำหน้าจะไม่เผยหมายเลขไพ่ก่อนเปิด ไพ่ที่เลือกไม่ซ้ำกันในการเปิดหนึ่งรอบ
- เมื่อเปิดแล้วสามารถกดหน้าไพ่เพื่อพลิกกลับ และกด **อ่านคำทำนาย** เพื่อดูรายละเอียด
- **ไม่มีโหมดครึ่งวงกลม (Arc Mode)** ใน V7

## 2. โครงสร้างโปรเจกต์

```text
thai-divine-cards/
├── index.html              หน้าเว็บหลัก
├── css/
│   └── style.css           สี Layout และ Animation
├── js/
│   ├── app.js              การสุ่ม สับ เลือก พลิก และแสดงคำทำนาย
│   ├── config.js           การตั้งค่าแอปและจำนวนไพ่
│   └── cards-data.js       ชื่อไพ่และคำทำนาย
├── images/                 สร้างโฟลเดอร์นี้เมื่อมีรูปจริง
│   ├── card-back.jpg       รูปหลังไพ่ที่ใช้ร่วมกัน
│   └── cards/
│       ├── 1.jpg           รูปหน้าไพ่ใบที่ 1
│       ├── 2.jpg
│       └── ...
└── README.md               คู่มือฉบับนี้
```

หากยังไม่มีรูปจริง แอปใช้ภาพสำรองที่สร้างจาก CSS ให้ จึงทดลองเปิดไพ่ได้ก่อนถ่ายรูปครบสำรับ

## 3. ใช้งานบนเครื่อง (Local)

1. แตก ZIP และเก็บไฟล์ทั้งหมดไว้ในโฟลเดอร์เดียวกันตามโครงสร้างข้างบน
2. ดับเบิลคลิก **`index.html`** เพื่อเปิดใน Chrome, Edge หรือ Safari บนคอมพิวเตอร์
3. เลือกโหมดแล้วทดลองเปิดไพ่ได้ทันที โดยไม่ต้องเปิด Local Server
4. หลังแก้ไฟล์ ให้ Refresh หน้าเว็บ (บน Windows ลอง `Ctrl+F5` หากยังเห็นข้อมูลเก่า)

แอปโหลดการตั้งค่าและคำทำนายผ่าน `<script>` ไม่ใช้ `fetch()` จึงเปิดผ่าน `file://` ได้ในเบราว์เซอร์ทั่วไป ทั้งนี้การเปิดไฟล์จาก OneDrive ในหน้าเว็บไม่ใช่การโฮสต์เว็บไซต์; หากต้องการเปิดผ่านลิงก์บนมือถือ ให้ใช้ GitHub Pages

## 4. เปลี่ยนจำนวนไพ่และตั้งค่า

แก้ **`js/config.js`** ซึ่งใช้ `window.APP_CONFIG` เช่น:

```javascript
window.APP_CONFIG = {
  "appName": "ไพ่เทพพยากรณ์",
  "subtitle": "เปิดไพ่เพื่อค้นหาข้อคิดและแนวทางของคุณ",
  "cardCount": 80,
  "quickChoiceCount": 21,
  "cardImagePath": "images/cards/",
  "cardImageExtension": ".jpg",
  "cardBackImage": "images/card-back.jpg",
  "defaultDrawCount": 1,
  "drawOptions": [1, 3, 5, 10],
  "allowReversed": false,
  "enableSound": true,
  "shuffleDurationMs": 2100,
  "theme": {
    "accent": "#d8ae65",
    "background": "#100c16"
  }
};
```

| ค่า | ความหมาย |
| --- | --- |
| `cardCount` | จำนวนไพ่ทั้งสำรับ ค่าเริ่มต้น 80; โค้ดรองรับจำนวนเต็ม 1–2000 |
| `quickChoiceCount` | จำนวนไพ่คว่ำหน้าให้เลือกใน Quick Draw ค่าเริ่มต้น 21; ถ้าเลือกเปิดมากกว่านี้ ระบบพยายามแสดงให้เพียงพอตามจำนวนไพ่ที่มี |
| `drawOptions` | ตัวเลือกจำนวนไพ่สำหรับ Quick และ Grid; ค่าเกินจำนวนสำรับจะถูกตัดออก |
| `defaultDrawCount` | จำนวนไพ่ที่เลือกไว้ตอนเข้า Quick/Grid (ต้องอยู่ใน `drawOptions` ที่ใช้ได้) |
| `cardImagePath` / `cardImageExtension` | ตำแหน่งและนามสกุลภาพหน้าไพ่ |
| `cardBackImage` | ตำแหน่งภาพหลังไพ่ |
| `enableSound` | เปิด/ปิดเสียงเอฟเฟกต์เริ่มต้น |
| `shuffleDurationMs` | ระยะเวลา Animation สับไพ่ (มิลลิวินาที; โค้ดกำหนดขั้นต่ำ 1500) |
| `theme.accent` / `theme.background` | สีทองหลักและสีพื้นหลัง |
| `allowReversed` | กำหนดว่าจะให้แสดงช่องคำอธิบายไพ่กลับหัวหรือไม่; **ไม่ได้เปิดระบบสุ่มไพ่กลับหัว** |

**ตัวอย่าง:** หากตรวจสอบแล้วสำรับจริงมี 69 ใบ ให้เปลี่ยน `cardCount: 69` แล้วเพิ่มภาพ `1.jpg` ถึง `69.jpg` ตามหมายเลขที่แมปไว้ ไม่ต้องแก้ `app.js`

## 5. เพิ่มภาพไพ่จริง

- ภาพหลังไพ่: `images/card-back.jpg`
- ภาพหน้าไพ่: `images/cards/1.jpg`, `images/cards/2.jpg`, ... ตามหมายเลข `id`
- ถ้าใช้ PNG ทั้งสำรับ ให้แก้ `cardImageExtension` เป็น `.png`
- ใช้ชื่อไฟล์ให้ตรงทุกตัวอักษร รวมถึงตัวพิมพ์เล็ก/ใหญ่บน GitHub Pages
- แนะนำให้ครอปให้เห็นไพ่เต็มใบ และบีบอัดภาพให้เหมาะกับมือถือ
- ภาพที่ยังไม่พบจะแสดงภาพสำรอง ไม่ทำให้ระบบสุ่มหยุดทำงาน

หากถ่ายภาพไพ่หลายใบในภาพเดียว สามารถแยกและตั้งชื่อภาพย่อยก่อนนำไปวางใน `images/cards/` ได้ โดยตรวจสอบหมายเลขจริงก่อนแมป

## 6. เพิ่มชื่อและคำทำนาย

แก้ **`js/cards-data.js`** โดยคงโครงสร้าง `window.CARDS_DATA` และ `cards` ซึ่งเป็น Array ไว้:

```javascript
window.CARDS_DATA = {
  "cards": [
    {
      "id": 1,
      "name": "ชื่อไพ่ตามสำรับจริง",
      "name_th": "ชื่อไพ่ภาษาไทย",
      "keywords": ["คำสำคัญ 1", "คำสำคัญ 2"],
      "meaning": "คำอธิบายหลัก",
      "love": "ความรัก",
      "career": "การงาน",
      "finance": "การเงิน",
      "advice": "คำแนะนำ",
      "reversed": "ความหมายเมื่อกลับหัว (ถ้ามี)"
    }
  ]
};
```

- `id` ต้องเป็นจำนวนเต็มและตรงกับชื่อไฟล์ภาพ เช่น `id: 1` → `1.jpg`
- ใส่ข้อมูลเฉพาะใบที่มีแล้วได้ ไม่ต้องกรอกครบ 80 ใบตั้งแต่ต้น
- ใบที่ไม่มีข้อมูลจะแสดงชื่อ/ข้อความสำรอง ไม่สร้างความหมายเอง
- `keywords` ต้องเป็น Array; ช่องข้อความอื่นสามารถปล่อยเป็น `""` ได้
- หากเพิ่มหลายรายการ ให้คั่นด้วยเครื่องหมายจุลภาค `,` และรักษา Syntax JavaScript ให้ถูกต้อง
- ควรตรวจสอบชื่อและความหมายกับคู่มือของสำรับจริงก่อนใช้งาน

## 7. เผยแพร่บน GitHub Pages

1. สร้าง Repository บน GitHub เช่น `thai-divine-cards`
2. อัปโหลด **เนื้อหาภายในโฟลเดอร์โปรเจกต์** ไปยัง Repository โดยให้ `index.html` อยู่ที่ Root
3. เปิด **Settings → Pages**
4. ใน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก Branch `main` และ Folder `/(root)` แล้วกด **Save**
6. รอ Deploy และเปิด `https://YOUR-USERNAME.github.io/thai-divine-cards/`

เมื่อแก้ไขภาพหรือไฟล์ในอนาคต ให้ Commit/Push ไฟล์ที่เปลี่ยนขึ้น Repository แล้วรอให้ GitHub Pages Deploy อีกครั้ง

**ความเป็นส่วนตัว:** GitHub Pages แบบปกติเป็นเว็บไซต์สาธารณะ แม้มีผู้ใช้เพียงคนเดียวก็ไม่ถือว่าล็อกการเข้าถึง อย่าอัปโหลดภาพหรือข้อความที่ไม่ต้องการเผยแพร่ และตรวจสอบสิทธิ์การใช้ภาพไพ่จากเจ้าของผลงานก่อนเผยแพร่

## 9. ข้อจำกัดและหมายเหตุ

- ไม่มีระบบบัญชีผู้ใช้, Admin, Database, AI หรือประวัติการเปิดไพ่
- ข้อมูลคำทำนายแก้ในไฟล์ JavaScript ไม่ได้บันทึกกลับไฟล์จากหน้าเว็บโดยตรง
- โหมด Instant เปิด 1 ใบเสมอ; `drawOptions` มีผลกับ Quick และ Grid
- การแสดงตำแหน่งไพ่มีป้ายเฉพาะสำหรับ 1, 3 และ 5 ใบ; จำนวนอื่นใช้ป้ายลำดับใบทั่วไป
- การแก้ไฟล์ Local จะไม่เปลี่ยนไฟล์บน GitHub จนกว่าจะอัปโหลดและ Commit
- เว็บนี้เป็นเครื่องมือเปิดไพ่เพื่อความบันเทิงและการสะท้อนข้อคิด ไม่รับประกันการพยากรณ์อนาคต
